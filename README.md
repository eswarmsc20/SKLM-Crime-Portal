# ఆంధ్రప్రదేశ్ పోలీస్ - శ్రీకాకుళం జిల్లా నేర సమీక్ష పోర్టల్
## Andhra Pradesh Police - Srikakulam District Crime Review Portal
### Superintendent of Police Monthly Crime Review Dashboard & Reporting System

---

## 📌 పరిచయం (Overview)
శ్రీకాకుళం జిల్లా పోలీస్ విభాగం మరియు గౌరవనీయులైన **Superintendent of Police (SP)** గారి అధ్యక్షతన జరిగే జిల్లా వ్యాప్త క్రైమ్ మీటింగ్స్ (District Crime Review Meetings) లో అన్ని పోలీస్ స్టేషన్ల కేసుల వివరాలు (Point-1 & Point-2: All Head-wise Grave & Non-Grave UI Cases, Long Pending Cases, Compliance, Abstract Statistics) త్వరితగతిన సమీక్షించడానికి, శోధించడానికి మరియు రిపోర్ట్‌లు జనరేట్ చేయడానికి రూపొందించబడిన ఆధునిక వెబ్ పోర్టల్ ఇది.

ఈ ప్రాజెక్ట్‌ను సులభంగా **GitHub Pages** లేదా ఇతర సర్వర్‌లలో ఆన్‌లైన్ చేయవచ్చు, అలాగే ఇంటర్నెట్ లేకపోయినా లోకల్ కంప్యూటర్‌లో 1-క్లిక్‌తో ఓపెన్ చేసి ప్రొజెక్టర్‌పై ప్రదర్శించవచ్చు.

## 📂 ఇంటిగ్రేట్ చేయబడిన మాడ్యూల్స్ (Integrated Modules)

1. **📊 SP Executive Overview (క్రైమ్ సమీక్ష సారాంశం):**
   - జిల్లా వ్యాప్తంగా మొత్తం రిపోర్టెడ్ కేసులు (68,206), Total UI కేసులు (2,597), Actual Active UI కేసులు (1,855), Long Pending UI కేసులు (397).
   - తీవ్రమైన నేరాలు vs సాధారణ నేరాలు (Grave vs Non-Grave UI: 150 vs 2,447).
   - కోర్టు నంబర్ల కోసం నిరీక్షిస్తున్న కేసులు (SC/PRC/CC Awaited: 742).
   - డైనమిక్ చార్ట్స్: నేర వర్గీకరణ, కేసుల పెండెన్సీ కాల పరిమితి (<45 రోజులు, 3-6 నెలలు, 1 సంవత్సరం పైబడినవి), టాప్ 10 పెండింగ్ పోలీస్ స్టేషన్లు, పెండెన్సీకి ప్రధాన కారణాలు.

2. **📋 Head-Wise Crime Statistics (2024, 2025 & 2026 Abstract):**
   - 4. Head Wise Abstract ఎక్సెల్ ఫైల్ ఆధారంగా 2024, 2025, 2026 సంవత్సరాల పూర్తి గణాంకాలు.
   - Bodily Offences, Crime Against Women, POCSO, Property Offences, SC/ST కేసులు, Fatal Accidents, White Collar Offences, Cyber Crime, Enforcement, Missing, 174 CrPC.
   - శాతం మార్పుల ఆధారంగా రంగుల బ్యాడ్జీలు (నేరాలు తగ్గినచో ఆకుపచ్చ/Green, పెరిగినచో ఎరుపు/Red).

3. **🔍 Total UI Cases Explorer (Point-1 & 1A సమగ్ర రిజిస్ట్రీ):**
   - మొత్తం 2,597 UI కేసుల శోధన మరియు ఫిల్టర్ ఇంజిన్.
   - పోలీస్ స్టేషన్ (36 PS), సబ్-డివిజన్, సర్కిల్, నేర శీర్షిక (Crime Head), గ్రావిటీ (Grave/Non-Grave), టైమ్‌లైన్, పెండెన్సీ కారణాల ఆధారంగా మల్టీ-ఫిల్టరింగ్.
   - ఏ కేస్ పైన క్లిక్ చేసినా పూర్తి ఎఫ్.ఐ.ఆర్ వివరాలు, సెక్షన్లు, ఇన్వెస్టిగేషన్ ఆఫీసర్ (IO), బ్రీఫ్ ఫ్యాక్ట్స్ (Brief Facts of the Case) చూపే మోడల్ పాపప్.

4. **⏳ Long Pending Priority Cases (Point-2 & 2A):**
   - 1 సంవత్సరం నుండి 10 సంవత్సరాలకు పైగా పెండింగ్‌లో ఉన్న 397 ముఖ్యమైన కేసుల ప్రత్యేక లిస్ట్.
   - రోజుల వారీగా క్రమబద్ధీకరణ (Days Pending descending).
   - ఎస్పీ గారు స్టేషన్ హౌస్ ఆఫీసర్లను (SHOs) నేరుగా ప్రశ్నించేందుకు మరియు గడువు విధించేందుకు అనుకూలమైన విభాగం.

5. **⚖️ Meeting Compliance & Progress (Point-1B):**
   - గత క్రైమ్ మీటింగ్ vs ప్రస్తుత క్రైమ్ మీటింగ్ ప్రగతి సమీక్ష.
   - PT / Court Disposal అయిన కేసులు, అదనంగా అందిన CC నంబర్లు, అరెస్ట్ అయిన నిందితుల సంఖ్య.

6. **🏛️ Police Station 360° Dossier (స్టేషన్ ప్రొఫైల్ కార్డ్):**
   - జిల్లాలోని 36 పోలీస్ స్టేషన్లలో ఏ స్టేషన్ అయినా ఎంచుకోవచ్చు (ఉదా: శ్రీకాకుళం I టౌన్, కాశీబుగ్గ, టెక్కలి, పలాస, ఎచ్చెర్ల, గార, హిరమండలం, మొదలైనవి).
   - ఆ స్టేషన్ పరిధిలోని కేసుల క్లియరెన్స్ రేటు %, పెండెన్సీ కారణాలు, IO ల వారీగా ఉన్న కేసులు మరియు పెండింగ్ FIR ల జాబితా.

7. **📽️ Live Crime Meeting Presentation Mode (ప్రొజెక్టర్ స్క్రీన్ మోడ్):**
   - జిల్లా హెడ్ క్వార్టర్స్‌లోని సమావేశ మందిరంలో ప్రొజెక్టర్‌పై ప్రదర్శించడానికి ప్రత్యేక ఫుల్-స్క్రీన్ వ్యూ.
   - స్టేషన్ల వారీగా ఎస్పీ గారి రివ్యూ చెక్‌లిస్ట్ మరియు ఆదేశాలు.

8. **📄 Reports & Export Center (ఎక్సెల్ మరియు ప్రింట్ రిపోర్ట్‌లు):**
   - SheetJS ద్వారా క్షణాల్లో ఏ రిపోర్ట్ అయినా `.xlsx` ఎక్సెల్ ఫార్మాట్‌లో డౌన్‌లోడ్ చేసుకునే సదుపాయం.
   - A4 పేపర్ సైజులో ప్రింట్ తీసుకోవడానికి ప్రత్యేక ప్రింట్ స్టైల్ షీట్.

## 🚀 కంప్యూటర్‌లో రన్ చేయడం ఎలా? (How to Run Locally)

### విధానం 1: (అత్యంత సులభం - 1 క్లిక్)
* ఫోల్డర్‌లోని **`start_portal.bat`** ఫైల్‌ను డబుల్ క్లిక్ చేయండి.
* వెంటనే లోకల్ వెబ్ సర్వర్ స్టార్ట్ అయి మీ బ్రౌజర్‌లో పోర్టల్ ఓపెన్ అవుతుంది.

### విధానం 2: (PowerShell ద్వారా)
```powershell
.\start_portal.ps1
```

### విధానం 3: (నేరుగా ఫైల్ ఓపెన్ చేయడం)
* మీరు ఎటువంటి సర్వర్ లేకుండా కూడా నేరుగా **`index.html`** ఫైల్‌ను Chrome లేదా Edge బ్రౌజర్‌లో డబుల్ క్లిక్ చేసి రన్ చేసుకోవచ్చు (ఆఫ్‌లైన్‌లో కూడా పనిచేస్తుంది).

## 🌐 GitHub లో ఉంచి ఆన్‌లైన్ (GitHub Pages) చేయడం ఎలా?

మీరు ఈ పోర్టల్‌ను GitHub లో ఉంచి ఆన్‌లైన్ లింక్ ద్వారా ఎక్కడినుండైనా (మొబైల్, ట్యాబ్లెట్, లాప్‌టాప్) యాక్సెస్ చేయడానికి ఈ క్రింది స్టెప్స్ పాటించండి:

### స్టెప్ 1: GitHub లో కొత్త రిపాజిటరీని సృష్టించండి
1. మీ [GitHub](https://github.com) ఖాతాలోకి లాగిన్ అవ్వండి.
2. పైన ఉన్న `+` గుర్తు క్లిక్ చేసి **New repository** ఎంచుకోండి.
3. Repository Name: `sklm-crime-review` (లేదా మీకు నచ్చిన పేరు) ఇవ్వండి.
4. `Public` ఎంచుకొని **Create repository** పై క్లిక్ చేయండి.

### స్టెప్ 2: మీ కోడ్‌ను GitHub కు పుష్ చేయండి
కమాండ్ ప్రాంప్ట్ లేదా PowerShell ఓపెన్ చేసి ఈ ఫోల్డర్‌లో ఈ కమాండ్స్ రన్ చేయండి (మీ GitHub యూజర్ నేమ్ తో మార్చండి):

```bash
git add .
git commit -m "Initial release of Srikakulam District Police Crime Review Portal"
git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/sklm-crime-review.git
git push -u origin main
```

*(గమనిక: 180MB ముడి జిప్ ఫైల్ `.gitignore` లో చేర్చబడింది కాబట్టి GitHub లో ఫైల్ సైజు పరిమితి సమస్య రాదు).*

### స్టెప్ 3: GitHub Pages ఆన్ చేయండి (ఉచిత ఆన్‌లైన్ హోస్టింగ్)
1. GitHub లో మీ రిపాజిటరీ లోపల **Settings** ట్యాబ్‌కు వెళ్లండి.
2. ఎడమవైపు మెనూలో **Pages** పై క్లిక్ చేయండి.
3. **Build and deployment** విభాగంలో:
   - Source: `Deploy from a branch`
   - Branch: `main` మరియు ఫోల్డర్: `/(root)` ఎంచుకొని **Save** క్లిక్ చేయండి.
4. 1-2 నిమిషాల్లో మీకు ఒక లైవ్ లింక్ లభిస్తుంది:
   `https://<YOUR-GITHUB-USERNAME>.github.io/sklm-crime-review/`
5. ఈ లింక్‌ను ఎస్పీ గారు మరియు ఇతర అధికారులతో షేర్ చేసి నేరుగా ఉపయోగించవచ్చు!
